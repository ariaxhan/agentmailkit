agentmailkit sample emails

Real output. Live APIs, a real model, and the deterministic renderer that owns every byte of markup. Nothing here was hand-written or touched up.

Morning Brief

Open-Meteo weather, three news outlets kept separate so their framings can be compared, and Wikipedia's on-this-day. Note the paragraph contrasting how two outlets covered the same story: that comparison only exists because the feeds stay labelled all the way into the prompt.

warm theme · weather + news + history

Curiosity

Archaeology and astronomy feeds plus a historical entry. No work content and no productivity framing, on purpose: an inbox that only ever contains work stops getting opened.

ink theme · rss + history

Every email is one JSON job spec plus a markdown prompt. The model writes only the words; the theme produces the HTML, so the layout is byte-identical every run and house style (no em dashes) is enforced in code rather than requested from a model. Run them yourself with agentmailkit run morning-brief --dry-run.
